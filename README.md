## 📌 Sobre o Projeto

Este é o meu portfólio profissional desenvolvido para apresentar meus principais projetos, habilidades técnicas, experiência com desenvolvimento backend e canais de contato. 

O site é hospedado diretamente via **GitHub Pages**, construído com foco em **alta performance**, **design responsivo (Mobile First)** e **código limpo sem dependência de frameworks pesados**.

---

## 🛠️ Tecnologias Utilizadas

### Core & Estilização
- **HTML5 Semântico**: Estrutura acessível com metadados SEO e Open Graph para compartilhamento social.
- **CSS3 Vanilla**: Sistema de design moderno baseado em variáveis HSL, flexbox, CSS grid e design responsivo.
- **JavaScript Vanilla**: Lógica de interação leve e modular.

### Bibliotecas & Integrações
- [Swiper.js](https://swiperjs.com/) - Carrossel interativo e responsivo para visualização dos projetos.
- [Typed.js](https://github.com/mattboldt/typed.js/) - Animação de digitação dinâmica para apresentação dos perfis técnicos.
- [ScrollReveal](https://scrollrevealjs.org/) - Animações suaves de revelação durante a rolagem de tela.
- [EmailJS](https://www.emailjs.com/) - Envio assíncrono de mensagens pelo formulário de contato sem necessidade de servidor backend próprio.
- [Remix Icon](https://remixicon.com/) - Conjunto de ícones vetoriais modernos.

## 🚀 Como Executar Localmente

1. **Clone o repositório:**
   ```bash
   git clone https://github.com/LeandroFFBR/leandroffbr.github.io.git
   ```

2. **Acesse a pasta do projeto:**
   ```bash
   cd leandroffbr.github.io
   ```

3. **Abra o arquivo `index.html`:**
   - Dê um duplo clique no arquivo `index.html` ou utilize a extensão **Live Server** no seu editor de código.
